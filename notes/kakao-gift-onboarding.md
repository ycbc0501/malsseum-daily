# A트랙 — 출판·저작권 (입점보다 먼저)

카카오 서류보다 이게 선행이다. 출판사 신고 없이는 판매용 도서를 낼 수 없고,
ISBN 없이는 정가 표시가 안 되고, 정가 없이는 카카오에 등록이 안 된다.

## A-1. 번역본 저작권 — 최우선 확인 사항
확인된 사실:
- 허가 주체는 **교회가 아니라 대한성서공회(KBS)**. 저작권부 02-2103-8730.
- KBS는 한글 성경의 **2차적저작물 저작권자**. 2019년 법원이 개역개정을
  "창작성 있는 번역저작물"로 인정 → 무단 사용은 명백한 침해.
- **개역한글판(1961)은 보호기간 50년 경과로 저작권료 없이 사용 가능** ← KBS 공식 FAQ.
  단 성명표시권·동일성유지권은 존속 → 출처 표기 필수, 본문 문구 변경 불가(편집·레이아웃은 무방).
- 개역개정 라이선스 비용은 생각보다 낮음: **단행본 판매정가의 3~5%**, 허가기간 1년,
  편집 견본 사전 제출·협의.

→ 결론: "너무 오래 걸려서 직접 번역"은 **불필요한 우회였을 가능성이 큼.**
   개역한글판은 공짜이고, 개역개정도 정가의 3~5%면 끝난다.

- [x] **(a) 원문 직접 번역으로 확인됨** → 우리 저작물. KBS 라이선스 불필요.
- [ ] **번역 작업 기록 보존** — 원문 대조 노트, 초고, 작업 이력. 나중에 "개역개정을
      베낀 것 아니냐"는 주장이 나올 때 **독자적 창작의 증거**가 된다. 지금 정리해두면 공짜,
      나중에 만들려면 불가능.
- [ ] **감수(監修) 확보** — 법적 문제와 별개로, 한국 교계는 역본을 매우 중시함.
      무명 출판사의 자체 번역은 신뢰 확보가 어렵고 최악의 경우 이단 시비가 붙는다.
      신학교 교수·목회자 감수를 받아 판권면에 표기하면 이 리스크가 크게 줄고,
      카카오 제안서에도 쓸 수 있는 근거가 된다.

## A-2. 인스타 계정 — 자체 번역으로 교체 (권장)
현황: `verses.json`에 `"translation": "개역개정"`. README에 미해결 액션아이템으로 이미 기록돼 있음.
상품 홍보 채널이므로 순수 개인 사용으로 보기 어려움 → 무허가 상태.

선택지 셋:
| 안 | 저작권 | 비용 | 마케팅 |
|---|---|---|---|
| 개역개정 유지 | ❌ 무허가 | 정가의 3~5% (책 기준) | 책과 본문이 다름 |
| 개역한글 전환 | ✅ PD | 0 | 책과 본문이 다름 |
| **자체 번역 전환** | ✅ 우리 것 | 0 | **매 포스트가 제품 샘플** |

→ **자체 번역 전환이 정답.** 저작권 문제가 사라지고, 계정이 홍보하는 바로 그 텍스트를
   매일 노출하게 되며, `metrics.json`으로 **인쇄 전에** 번역 문체의 반응을 측정할 수 있다.
   자체 번역의 최대 약점(낯섦·신뢰)을 출간 전에 미리 해소하는 유일한 방법이기도 하다.

- [ ] 번역된 구절을 `verses.json` 형식으로 받기 (책 진행분만이라도)
- [ ] `"translation"` 필드 갱신 + 오버레이 출처 표기에 역본명 노출 검토
- [ ] ⚠️ **줄바꿈 재검증 필수** — 문체가 다르면 기존 줄나눔 점수가 달라짐.
      CONTENT_RULE의 줄바꿈 원칙(동사구·수식어-피수식어 분리 금지) 기준으로 전 구절 재채점.

## A-3. 출판 등록 — 두 갈래, 선택 사항임 (2026-08-03 확인)
"출판사 신고를 꼭 해야 하나"의 답: **판매 자체는 신고 없이도 가능.**
출판사 신고는 *서점 유통*을 위한 것이지, 판매의 전제 조건이 아니다.

**루트 A — 독립출판 / 굿즈로 판매**
- 출판사 신고 ✕, ISBN ✕, **도서정가제 적용 ✕**
- 카카오에서 할인·쿠폰·프로모션 **자유** ← 선물하기에서 이게 결정적
- 카카오 카테고리는 리빙/문구/디자인 계열로 등록
- 단점: 교보·예스24 등 일반 서점 유통 불가

**루트 B — 정식 출판**
- [ ] 출판사 신고 — 관할 구청 문화체육과. 등록면허세 27,000원, 약 3일~1주. **전혀 안 느림**
- [ ] ISBN — 국립중앙도서관 서지정보유통지원시스템(seoji.nl.go.kr). 출판사 신고증 필요
- [ ] 정가 표시 → **도서정가제 15% 상한**(가격할인 10% + 간접할인 5%)
- 장점: 서점 유통, 도서 카테고리 노출, 브랜드 신뢰도

→ 권장: **루트 A로 카카오 먼저 출시**, 서점 채널이 필요해지면 그때 신고+ISBN 붙여 재판.
   순서가 되돌릴 수 없는 게 아니다. 다만 성경은 서점 기독교 코너가 큰 채널이므로
   중장기적으로는 B로 가는 게 맞을 수 있음 — 초판 반응 보고 결정.

# B트랙 — 카카오 입점

## 0. 완료된 것
- [x] 통신판매업 신고 접수
- [x] 등록면허세 납부
- [x] (선행) 구매안전서비스(에스크로) 이용확인증 — 신고 시 첨부했으므로 발급 완료 상태

## 1. 지금 당장 (시한 있음)
- [ ] **통신판매업 신고증 출력** — 처리완료 문자 오면 정부24 `MyGOV > 나의 신청내역`에서 출력.
      **온라인 출력은 7일 이내만 가능.** 놓치면 관할 구청 방문해야 함. PDF + 인쇄본 둘 다 확보.

## 2. 카카오 계정/신청 경로
- 판매자센터: https://shopping-sell.kakao.com/hub
- 카카오계정으로 가입 → 좌측의 **"선물하기 입점 신청"** → **제휴제안** 작성
  - 톡스토어(오픈마켓형) 입점과 **선물하기 입점은 별개**. 톡스토어는 신청하면 대체로 열리지만,
    선물하기는 MD 심사를 통과해야 함. 우리가 원하는 건 선물하기.
- 제휴제안 유형 두 가지 — 신청 전에 결정해야 함:
  - **배송 상품**: 받는 사람이 주소를 입력하면 실물 배송. (포토북이면 이쪽)
  - **교환권**: 온·오프라인 교환처에서 실물로 바꾸는 쿠폰형.
- 절차: 입점 제안 → 담당자(MD) 검토 → 판매조건·상품 협의 → 계약 → 판매 시작

## 3. 서류
공통(카카오 명시):
- [ ] 사업자등록증 사본
- [ ] 본인서명사실확인서 사본 (인감증명서로 대체 가능)
- [ ] 통신판매업 신고증
- [ ] 정산용 통장 사본
- [ ] 법인인 경우: 법인등기부등본, 법인인감증명서, 사용인감계

브랜드 심사에 실질적으로 영향:
- [ ] 상표등록증 — 없으면 **출원 접수증이라도**. 등록까지 1년 이상 걸리므로 지금 출원 시작하는 게 이득.

도서 카테고리 (확정):
- [ ] 출판사 신고증 (A-3)
- [ ] ISBN (A-3)
- [ ] 번역본 라이선스 근거 — 개역한글판 사용 시 출처 표기, 개역개정 시 KBS 사용허락서 (A-1)

## 4. 제안서 — 붙고 떨어지는 건 사실상 여기서 갈림
서류는 자격 요건일 뿐. 담아야 할 것:
- [ ] **가격대별 기획 세트** — 3만 / 5만 / 7만원대에 맞춘 구성을 명시적으로 제시.
      선물하기는 "선물 가격대"로 탐색하는 채널이라 이게 가장 중요한 항목.
- [ ] **패키징 사진** — 선물하기에서는 포장이 곧 상품. 받는 순간의 경험을 보여줘야 함.
- [ ] 브랜드 스토리 / 왜 "선물"로 적합한가
- [ ] 기존 채널 매출 실적 (자사몰, 스마트스토어, 와디즈 등)
- [ ] SNS·브랜드 인지도
- [ ] 월 공급 가능 수량 — 선물하기는 트래픽 스파이크가 크므로 재고 대응 능력을 봄
- [ ] 채널 운영 계획 (시즌 기획, 프로모션 참여 의사)
- [ ] 원가/마진 — 수수료를 감당할 수 있는 구조인지

## 5. 샘플
- MD 검토 단계에서 **요청이 오면** 그때 안내받은 주소로 발송. 미리 임의 발송하지 말 것.
- 보낼 때:
  - [ ] 실제 고객이 받는 그대로의 완제품 포장 (박스, 완충재, 카드까지)
  - [ ] MD가 여러 명이 돌려보므로 여유분 2~3개
  - [ ] 브랜드 소개서 인쇄본 + 담당자 연락처 동봉

## 6. 계약·운영 (승인 후)
- [ ] 수수료율 협의 — 카테고리별 상이. **배송비 포함 총 판매가 기준**으로 수수료가 매겨지는
      구조가 문제된 전례가 있으니 계약서에서 과금 기준을 명시적으로 확인할 것.
- [ ] 정산 주기 / 세금계산서 발행 체계
- [ ] 상품 이미지 — 카카오 가이드 규격에 맞춰 재촬영 필요할 가능성 높음
- [ ] 상세페이지
- [ ] 택배사 계약, 출고 리드타임, 도서산간 정책
- [ ] 교환/반품 정책 — 선물하기는 "받은 사람이 교환"하는 케이스가 있어 일반몰과 다름
- [ ] CS용 카카오톡 채널 개설
- [ ] 주문 수신 방식: 판매자센터 수기 vs 솔루션 연동

## 7. 권장 순서
1. 신고증 출력 (7일 타이머)
2. 상표 출원 상태 확인 → 없으면 즉시 출원
3. 가격대별 세트 구성 확정 + 패키징 촬영
4. 제안서 작성
5. 판매자센터에서 선물하기 입점 신청
6. 샘플 요청 대응

## 확인 안 된 것 (추측하지 않음)
- 정확한 수수료율 — 공개 자료 없음. 협의 단계에서 확인.
- 심사 소요 기간 — 공개 자료 없음.
- 샘플 발송이 필수 절차인지 MD 재량인지 — 공식 문서에 명시 없음.
